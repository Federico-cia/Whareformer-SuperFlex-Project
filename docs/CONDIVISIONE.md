# Condivisione del progetto

La repository contiene codice mantenuto, configurazioni di esempio, memoria corrente, storia scientifica ed evidenze numeriche selezionate. README è l'ingresso unico. I contributi e i risultati di Federico in Whareformer restano attribuiti e preservati.

Dati RGB/maschere, feature, nuvole, mesh complete, checkpoint e credenziali non fanno parte di questo aggiornamento. [Asset richiesti](../context/evidence/ASSET_ESTERNI.md); i pacchetti dati si condividono separatamente rispettando le fonti originali. Il piccolo verificatore diagnostico JSON è un artefatto dichiarato del prototipo, non un checkpoint neurale.

Prima della pubblicazione: python tools/build_publication_inventory.py, python tools/check_repository.py, node tools/check_map.cjs e test pertinenti. Controllare la lista dei file e la base remota, mantenendo i contributi successivi del collega. Nessun force push.

La pubblicazione non certifica efficacia scientifica: [stato e limiti](../context/memory/STATO_LAVORO.md). [Memoria](../context/memory/README.md) · [Evidenze](../context/evidence/README.md).
